# BiBo experiment ledger

Every axis tested on BiBo from May to October 2026: what was asked, what it settled, and where the
evidence lives. 40 W&B projects, about 1,060 runs, all under the
[`ablations-tinycompany-ai`](https://wandb.ai/ablations-tinycompany-ai) entity.

- Verdicts and numbers before mid-September have a long-form write-up in [`timeline/`](../timeline/README.md),
  one topic per folder. This page is the index across all of it, plus everything after it.
- Open items are in [`TODO.md`](../TODO.md); the "Still to do" section below is the short list.
- Link formats: project `https://wandb.ai/ablations-tinycompany-ai/PROJECT`, run
  `https://wandb.ai/ablations-tinycompany-ai/PROJECT/runs/RUN_ID`.

## How to read it

| Verdict | Means |
|---|---|
| **SHIPPED** | in the current board's default flags |
| **CLOSED NEGATIVE** | measured and rejected; code may survive behind a flag |
| **TIE / PARKED** | nothing cleared the noise floor |
| **OPEN** | not tested yet, or tested without a conclusion |

**Noise floors are per stack and never transfer.** On the current 1B board (2000 steps,
big-holdout val, 256 x 1024 tokens) the seed-to-seed spread is about **0.023** (seed 23: 3.3248,
seed 42069: 3.3477, same flags). Same-seed reruns are bitwise identical, so paired same-seed
gaps are much tighter than that. Gaps quoted on one seed are marked *(1 seed)*.

## The current board

The architecture all recent results are measured on. W&B project
[`bibo-base-1b`](https://wandb.ai/ablations-tinycompany-ai/bibo-base-1b).

| Part | Setting |
|---|---|
| Size | 965.5M total, 144.5M active (102.5M active non-embedding), tied embeddings |
| Trunk | hidden 512, 10 layers, 4 query / 2 KV heads, head dim 128 |
| Attention | layer pattern block3: global at L0, L3, L6, L9, sliding window 128 elsewhere; QK-norm with learned per-dim gains; XSA with learnable per-head alpha (init 0); fused `attn_xsa` kernel |
| Positions | global layers NoPE, window layers full RoPE |
| Residual | AttnRes block 3, 1 site, per-dim carry with sigmoid scale; bf16 residual stream |
| FFN | L0: all-active ensemble 8 x 768; L1-L9: 64 routed experts, top-6, width 1024 |
| Experts | radial NormSiLU activation; MXFP8 (W8A8) expert GEMMs (`--moe_fp8 1`), L0 stays bf16 |
| Router | sigmoid scores, aux-loss-free bias balancing, top-k weights sum-normalised, Muon on the router |
| Optimizer | Muown (Muon variant, muon wd 0, gain lr x0.1), muon lr 1e-2, AdamW 5e-4 for vectors / embeddings, WSD schedule (10% warmup, 20% decay), Newton-Schulz ns8 |
| Loss | factored-softmax fused CE (`--ce_kernel`), no MTP, no auxiliary losses |
| Recipe | seq 1024 x batch 64 x accum 4 = 262k tokens / step; about 211-218k tps, 44.7 GB on an RTX PRO 6000 |
